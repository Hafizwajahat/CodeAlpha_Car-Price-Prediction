# CodeAlpha_CarPricePrediction
Regression model predicting car prices (brand, horsepower, engine size, mileage, etc.).
Includes cleaning, brand extraction ("brand goodwill"), feature engineering, model comparison (R2, MAE, RMSE) and feature importance.
Dataset: CarPrice_Assignment.csv (link in the task PDF). Run: `python car_price_prediction.py CarPrice_Assignment.csv`
